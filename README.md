# ARCFlow Mobile App

## EN

ARCFlow is an offline first mobile productivity application designed to help users track habits, manage daily tasks, monitor consistency, and analyze personal progress through a clean and professional dashboard.

ARCFlow focuses on habit tracking, task management, daily productivity analysis, progress visualization, and a contribution style consistency system.

## Main App Concept

ARCFlow is built as a personal productivity command center. The app helps users answer three main questions every day.

What should I do today?  
Which habits should I complete?  
Is my progress improving or declining?
