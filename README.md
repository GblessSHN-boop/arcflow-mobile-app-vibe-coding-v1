# ARCFlow Mobile App Vibe Coding

## English

**ARCFlow Mobile App** is an offline first mobile productivity application designed to help users build consistency, manage daily tasks, track habits, and analyze personal progress through a clean, formal, and professional dashboard.

ARCFlow is not only a checklist application. It is designed as a personal productivity command center where users can clearly understand what they need to do today, which habits should be completed, which tasks are most important, and how their daily progress is developing.

The application focuses on habit tracking, todo management, daily progress analysis, streak monitoring, contribution style calendar visualization, and offline local data management.

## Indonesia

**ARCFlow Mobile App** adalah aplikasi produktivitas mobile offline first yang dirancang untuk membantu pengguna membangun konsistensi, mengelola tugas harian, melacak habit, dan menganalisis progres pribadi melalui dashboard yang bersih, formal, dan profesional.

ARCFlow bukan hanya aplikasi checklist. Aplikasi ini dirancang sebagai pusat kontrol produktivitas pribadi agar pengguna dapat memahami apa yang perlu dikerjakan hari ini, habit apa yang harus diselesaikan, tugas mana yang paling penting, dan bagaimana perkembangan progres hariannya.

Aplikasi ini berfokus pada habit tracking, todo management, analisis progres harian, pemantauan streak, visualisasi kalender kontribusi, dan pengelolaan data lokal secara offline.

## What is ARCFlow?

ARCFlow is a mobile productivity system built for personal daily control. The app helps users organize habits, tasks, and progress in one structured workspace.

ARCFlow helps users answer three main daily questions.

```text
What should I do today?
Which habits should I complete?
Is my progress improving or declining?
```

The main goal is to make productivity measurable, visual, and consistent without requiring internet access or user login.

## Main Concept

ARCFlow is designed as a personal productivity command center.

The app combines:

```text
Habit Tracker
```

This direction makes ARCFlow more than a basic checklist app. It becomes a system for understanding daily consistency and long term personal progress.

## Planned Main Features

### Habit Tracker

A habit tracking system that allows users to add habits, check daily completion, monitor streaks, and review consistency.

### Todo List

A task management system for daily tasks, priority work, deadlines, subtasks, and completion status.

A dashboard based analysis system that summarizes daily performance, completed habits, completed tasks, and productivity score.

### Contribution Calendar

A visual consistency calendar inspired by contribution style activity grids.

### Streak Tracking

A consistency tracker that records active streaks, best streaks, and habit performance.

### Offline Local Data

A local first system that stores user data on device without requiring login or internet connection.

## Vibe Coding Workflow

In this repository, vibe coding refers to an experimental development workflow where the developer combines idea exploration, AI assisted planning, manual code control, visual direction, Git workflow, and structured documentation.

The purpose is not to randomly generate code. The purpose is to use AI as a development partner while the developer still controls the architecture, naming system, application direction, repository workflow, and final decisions.

## Local Development

Install dependencies:

```powershell
flutter pub get
```

Check connected devices:

```powershell
flutter devices
```

Run on connected Android device:

```powershell
flutter run
```

Run on a specific Android device:

```powershell
flutter run -d 10DD4D0NX90007C
```

Build Android APK:

```powershell
flutter build apk
```
