# ARCFlow Version 1.2.2 Changelog

## EN

ARCFlow version 1.2.2 fixes and revises the Home Dashboard and Habit Tracker based on direct runtime testing.

This revision removes the duplicate Add Habit quick action, adds working Quick Note, Add Task, and Check Today actions, improves Today Score so it reacts to habit progress and daily actions, replaces Mini Contribution Preview with Contributions in the Last Year, adds a contribution style yearly grid, improves Daily Insight, improves Add Habit input readability, stabilizes checklist animation keys, and adds lightweight dashboard entry animation for mobile devices.

## ID

ARCFlow versi 1.2.2 memperbaiki dan merevisi Home Dashboard serta Habit Tracker berdasarkan pengujian runtime langsung.

Revisi ini menghapus quick action Add Habit yang dobel, menambahkan fungsi Quick Note, Add Task, dan Check Today, memperbaiki Today Score agar bereaksi terhadap progress habit dan aksi harian, mengganti Mini Contribution Preview menjadi Contributions in the Last Year, menambahkan grid kontribusi tahunan bergaya GitHub, memperbaiki Daily Insight, meningkatkan keterbacaan input Add Habit, menstabilkan key animasi checklist, dan menambahkan animasi masuk dashboard yang ringan untuk perangkat mobile.
