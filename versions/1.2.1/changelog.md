# ARCFlow Version 1.2.1 Changelog

## EN

ARCFlow version 1.2.1 fixes the Habit Tracker dialog issue.

This patch fixes the Add Habit dialog lifecycle problem, improves keyboard handling, prevents large dialog overflow, and keeps habit checklist interactions stable.

Validated on physical Android device:
Add Habit works.
Checklist interaction works.
Complete All works.
Reset works.
Progress updates correctly.
Application label is ARCFlow.
