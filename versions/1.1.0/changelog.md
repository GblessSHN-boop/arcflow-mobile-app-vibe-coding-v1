# ARCFlow Version 1.1.0 Changelog

## EN

ARCFlow version 1.1.0 updates the Home Dashboard into a cleaner productivity command center.

This update improves the dashboard content with Today Score, Quick Actions, Today Habits, Priority Tasks, Mini Contribution Preview, and Daily Insight.

The dashboard visual direction is adjusted to a brighter black and white interface so it is easier to read, cleaner, and more comfortable for wider users.

## ID
