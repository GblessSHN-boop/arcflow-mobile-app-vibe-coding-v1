# ARCFlow Version 1.1.0 Development Notes

## EN

ARCFlow version 1.1.0 focuses on improving the Home Dashboard content.

This version will turn the starter dashboard into a productivity command center that shows daily score, quick actions, today habits, priority tasks, mini contribution preview, and daily insight.
