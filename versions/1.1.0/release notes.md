# ARCFlow Version 1.1.0 Release Notes

## EN

ARCFlow Mobile App version 1.1.0 focuses on the Home Dashboard content update.

This version introduces a clearer dashboard structure for daily productivity control. The screen now presents daily score, quick actions, today habits, priority tasks, mini contribution preview, and daily insight in one readable layout.

The visual direction is also adjusted from a very dark dashboard into a brighter black and white interface while keeping the application formal, clean, and professional.

## ID

ARCFlow Mobile App versi 1.1.0 berfokus pada pembaruan isi Home Dashboard.

Arah visual juga disesuaikan dari dashboard yang terlalu gelap menjadi tampilan hitam putih yang lebih cerah, tetapi tetap formal, bersih, dan profesional.
