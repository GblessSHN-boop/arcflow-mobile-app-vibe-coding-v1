# ARCFlow Version 1.2.0 Changelog

## EN

ARCFlow version 1.2.0 improves the Habit Tracker module.

This update fixes habit checklist interaction, removes the unmodifiable list issue, adds working habit controls, improves the habit progress display, and updates the application label to ARCFlow.

## ID

ARCFlow versi 1.2.0 meningkatkan modul Habit Tracker.

Pembaruan ini memperbaiki interaksi checklist habit, mengatasi masalah list yang tidak dapat dimodifikasi, menambahkan kontrol habit yang berfungsi, meningkatkan tampilan progress habit, dan memperbarui nama aplikasi menjadi ARCFlow.
