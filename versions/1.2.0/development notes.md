# ARCFlow Version 1.2.0 Development Notes

## EN

ARCFlow version 1.2.0 focuses on the Habit Tracker module.

This version will introduce the first core productivity feature of ARCFlow. Users will be able to see daily habits, check habit completion, review habit status, and understand simple daily habit progress.

## ID

ARCFlow versi 1.2.0 berfokus pada modul Habit Tracker.

Versi ini akan memperkenalkan fitur inti produktivitas pertama dari ARCFlow. Pengguna akan dapat melihat habit harian, melakukan checklist habit, melihat status habit, dan memahami progres habit harian secara sederhana.
